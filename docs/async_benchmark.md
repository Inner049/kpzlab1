# Аналіз прискорення асинхронного коду (ПР-12)

У результаті порівняння послідовної та паралельної вибірки даних за допомогою `asyncio.gather()` ми отримали значне прискорення роботи.

**Результати бенчмарку:**
* Послідовний час (SLOW): ~0.650 сек (0.3 + 0.2 + 0.15)
* Паралельний час (FAST): ~0.301 сек (max(0.3, 0.2, 0.15))
* **Загальне прискорення: ~2.1x**

*Тут має бути вставлений скріншот роботи скрипта `async_demo.py`*

**Висновки:**
Застосування `asyncio.gather()` дозволяє ініціювати декілька незалежних I/O операцій (наприклад, запитів до БД або API) одночасно. Загальний час очікування дорівнює часу найдовшої операції (0.3 сек), а не сумі всіх очікувань. Це критично важливо для швидкодії ендпоінтів у REST API. Також застосування фонових задач (`asyncio.create_task`) дозволяє миттєво повернути HTTP-відповідь користувачу, поки 'важка' операція (наприклад, генерація PDF) продовжує виконуватися у фоновому режимі.
